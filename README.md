# Papers 01 — Foundations: The Transformer & Pretraining

This presentation indexes the five publications that built the foundations of modern LLMs and traces the conceptual arc connecting them. **Attention Is All You Need** (Vaswani et al., 2017) introduced the Transformer, replacing recurrence with self-attention and making model training massively parallel. **BERT** (Devlin et al., 2018) established the pretrain→fine-tune paradigm with an encoder-only architecture trained via masked-language-modelling and next-sentence-prediction, giving deeply bidirectional context and seeding the embedding/reranker lineage still used in retrieval today. **GPT-3** (Brown et al., 2020) scaled a decoder-only autoregressive model to 175B parameters and revealed in-context learning — zero-, one-, and few-shot task performance through prompting alone, with no gradient updates — inventing prompt engineering. **Scaling Laws for Neural Language Models** (Kaplan et al., 2020) showed that test loss follows smooth, extrapolable power laws in model size, dataset size, and compute, turning model design into a budgeting exercise. Finally, **Chinchilla** (Hoffmann et al., DeepMind, 2022) corrected the scaling picture: for a fixed compute budget, parameters and tokens should scale roughly equally (~20 tokens per parameter), proving most prior giant models were badly undertrained — Chinchilla-70B trained on 1.4T tokens beats the 4×-larger Gopher-280B. Together they explain why every model you deploy is a Transformer, why scale unlocks emergent abilities, and why smaller, data-richer models are so often the right deployment choice.
